## Workflow Answer

### Story/script → generation → edit → final

1. **Script and story structure — Claude Code + Codex:** Develop or refine the premise, hook, escalation, reversal, and final payoff. Convert the approved script into structured scenes, dialogue/voiceover, character actions, shot durations, and production requirements.
2. **Character, environment, and keyframes — GPT Image 2 + Google Nano Banana:** Build consistent character sheets, expression and wardrobe references, environment designs, prop references, and hero keyframes. Lock stable reference IDs, palette, lighting, lens language, and forbidden variations in a character/world bible.
3. **Storyboard and shot planning — Claude Code + Codex:** Turn the story into a vertical storyboard and machine-readable shot manifest covering framing, lens feel, camera movement, screen direction, performance, duration, transition intent, audio cue, prompt, model, and reference assets.
4. **Video generation — MiniMax H3 + Kling + Seedance + Higgsfield + Veo:** Select the best generator for each shot rather than forcing one model across the film. Use image-to-video, first/last-frame, character/reference, and motion controls where available; keep shots modular and render edit handles.
5. **Continuity and artifact QA — Codex + Claude Code + manual review:** Compare every output with the approved character/world bible. Track face, wardrobe, props, geography, eyelines, hands, scale, lighting, camera direction, and motion; flag shots for regeneration or targeted repair.
6. **Assembly and finishing — Adobe Premiere Pro:** Assemble selects, refine pacing, synchronize voiceover, add music, ambience, Foley/SFX, transitions, captions, colour matching, and subtle grain. Codex and Claude Code support this stage by preparing edit decision lists, shot manifests, subtitle files, filename/version checks, and Premiere-compatible automation scripts; final editorial decisions remain in Premiere Pro.
7. **Export and delivery — Adobe Premiere Pro + Codex/Claude Code QA:** Export 9:16 masters for TikTok, Reels, and Shorts, plus requested hook variations. Use scripted checks for duration, resolution, frame rate, naming, missing assets, caption-safe areas, and delivery completeness before manual playback approval.

Antigravity and n8n can automate repetitive asset routing, metadata, file naming, status tracking, and review handoffs, while creative direction and final shot approval remain manual.
