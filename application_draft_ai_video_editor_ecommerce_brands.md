## Production Workflow

1. **Brief and script breakdown — Claude Code + Codex:** Convert the supplied script, VO, brand details, and reference into hooks, claims, scenes, shot durations, required product moments, caption beats, and delivery specifications.
2. **Character/product/world assets — GPT Image 2 + Google Nano Banana:** Build approved talent references, product-safe keyframes, environments, wardrobe, expressions, and stylized look frames. For Pixar/3D or claymation, lock material, proportions, lighting, and facial design before motion.
3. **Shot planning — Codex + Claude Code:** Create a structured shot manifest covering reference files, framing, camera angle, movement, prompt, model, duration, text overlay, transition, and audio cue.
4. **Generation — MiniMax H3 + Kling + Seedance + Higgsfield + Veo/Runway:** Select the model per shot. Use image-to-video, reference, first/last-frame, camera, and motion controls where available. For AI interviews, separately manage presenter consistency, eyelines, lip-sync, cutaways, and reaction shots.
5. **Continuity and artifact QA — manual review + coding-agent checks:** Compare characters, product geometry, wardrobe, props, hands, lip-sync, lighting, screen direction, and branding against approved references. Regenerate or repair failed clips before editing.
6. **Editing and polish — Adobe Premiere Pro:** Assemble selects, create hook-first pacing, add captions, B-roll, graphic emphasis, music, ambience, Foley/SFX, colour matching, and platform-specific reframing. Codex and Claude Code can prepare edit lists, subtitle files, shot manifests, asset/version checks, and Premiere automation scripts.
7. **Export and delivery — Premiere Pro + automated QA:** Export required 9:16, 4:5, 1:1, or 16:9 versions. Verify duration, resolution, frame rate, filenames, missing media, caption-safe zones, audio peaks, and deliverable completeness before manual playback approval.
